    CLXS0010 离开中枢回踩¶

    模型定位：捕捉价格突破线段或中枢之后、回踩一笔发生转折的进场时机——经典的「突破—回踩—转折」三段式买点。

    形态定义与判定条件¶

    CLXS0010 关注的是突破后的第一次回踩，判定过程分三步：

    1. 发生突破：价格以线段破坏的方式突破，或直接突破中枢区间；
    2. 等待回踩：突破之后不追高，等回踩的一笔走出来；
    3. 回踩转折：回踩一笔发生转折时，产生信号点。

    一个重要的排除条件：如果突破发生时第二个中枢已经完备，则不再产生信号——此时走势已进入更大级别的震荡，回踩的可靠性下降，宁可不做的。

    卖点与买点完全对称：向下跌破线段或中枢后，等待反抽一笔转折，产生卖出信号。

    信号值与参数¶

    信号值遵循统一编码公式：

    信号值 = 方向 × (模型ID × 1000 + 次数 × 100 + 入场点类型)

    CLXS0010 的模型 ID 为 10，occurrence 固定为 1（单次触发），入场点类型由 SignalUtils 判定：

    信号值 含义
    10101 买入，结构信号
    10102 买入，Pin Bar
    10103 买入，吞没形态
    10104 买入，强分型
    10105 买入，MA5 拐头
    10107 买入，MACD 交叉
    -10101 ~ -10107 卖出侧对称（数值取负）

    参数说明：

    参数 默认值 说明
    WAVEOPT 1560 笔控制参数
    STRETCHOPT 0 线段控制参数
    TRENDOPT 0 走势控制参数
    MODELOPT 10 模型参数，低位数字 10 表示 CLXS0010；高位为 1（如 10010）表示套用走势划分，条件更宽松

    CLXS0010 支持走势方向过滤：宽松模式不判断走势方向，在所有线段中寻找信号；严格模式只在顺势方向寻找信号（下跌走势只找买点，上涨走势只找卖点）。

    调用示例¶

    Python 端函数签名与其他 CLXS 模型一致：

    highs = stock_day_data.high.to_list()
lows = stock_day_data.low.to_list()
opens = stock_day_data.open.to_list()
closes = stock_day_data.close.to_list()
volumes = stock_day_data.volume.to_list()
length = len(highs)
model_opt = 10  # CLXS0010；10010 表示套用走势划分
sigs: list[float] = fq_clxs(
    length, highs, lows, opens, closes, volumes,
    wave_opt, stretch_opt, trend_opt, model_opt)

    命令行选股：

    python -m fqlite.screen.clxs --model-opt 10
fqctl stock screen clxs --model-opt 10

    通达信公式（DLL 插件方式）：

    RESET:=TDXDLL7(1,0,0,0);
IG1:=TDXDLL7(2, 6, WAVEOPT, 0);
IG2:=TDXDLL7(2, 7, STRETCHOPT, 0);
IG3:=TDXDLL7(2, 8, TRENDOPT, 0);
IG4:=TDXDLL7(2, 9, MODELOPT, 0);
IG5:=TDXDLL7(2, 3, OPEN, 0);
IG6:=TDXDLL7(2, 5, VOL, 0);
SIG:=TDXDLL7(3,HIGH,LOW,CLOSE);
BUY_OPEN:SIG>0;
